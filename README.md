# SVG Generator

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**ロゴ用の文字を、ブラウザだけでSVGへ仕立てる小さな制作ツールです。** テキスト、フォント、色、サイズ、アイコンを調整し、そのままSVGとして書き出せます。

> 公開アプリ: [SVG Generator を開く](https://watanabe3tipapa.github.io/svg-generator/)

## まずは使う

1. **ロゴの文字**に、作りたい名称を入力します。変更はプレビューに自動反映されます。
2. フォント、サイズ、色、アイコン、配置を調整します。迷ったときは「シンプル」「アイコン付き」「横長ロゴ」のプリセットから始められます。
3. 右側の仕上がりを確認して、**SVGを書き出す**を選びます。SVGのマークアップをコピーしたい場合は「SVGコードをコピー」を使います。

## このツールでできること

| 項目 | 内容 | 使いどころ |
| --- | --- | --- |
| テキストとWebフォント | `Noto Sans JP` と `Inter` を切り替えて、文字・色・サイズ・線幅を調整 | まずロゴの見た目をつくる |
| フォントの追加 | `.ttf`、`.otf`、`.woff`、`.woff2` をブラウザ内で読み込み | 手元のブランドフォントを使う |
| アイコンと配置 | 丸・角丸の四角と、中央・左右寄せを指定 | シンボル付きの横長ロゴをつくる |
| アウトライン化 | 文字をパスとして保存 | 閲覧側にフォントがない環境でも形を保ちたい |
| フォント埋め込み | アップロードしたフォントをSVG内に含める | 編集可能な文字として共有したい。ただしファイルサイズは大きくなる |

## 大事な使い分け

### アウトライン化はいつ使うか

**アウトライン化**は文字をSVGのパスに変換する機能です。ロゴを画像素材として配布する場合や、利用先に同じフォントが入っていない可能性がある場合に向いています。アップロードしたフォントで使うと、より確実に文字をパスへ変換できます。

### フォント埋め込みはいつ使うか

**フォント埋め込み**は、アップロードしたフォントのデータをSVGに含める機能です。文字を編集可能なままフォント依存を減らせますが、ファイルは大きくなります。画像として使うだけなら、アウトライン化を優先してください。

### プライバシーとライセンス

アップロードしたフォントは**ブラウザ内でのみ処理**され、アプリのサーバーへ送信されません。フォントの利用条件、商用利用の可否、帰属表示の要否は、利用者自身で確認してください。

## ローカルで確認する

依存関係のインストールは不要です。リポジトリのルートで次を実行し、ブラウザで `http://localhost:8000/docs/` を開きます。

```bash
python3 -m http.server 8000
```

## プロジェクト構成

| ディレクトリ | 用途 |
| --- | --- |
| [`docs/`](docs/) | **公開アプリ本体**。GitHub Pages から配信されるロゴSVGジェネレーターです。 |
| [`app/`](app/) | SVG DOM操作の基礎を扱う、学習用の最小サンプルです。 |
| [`app2/`](app2/) | 図形の追加、移動、リサイズ、レイヤー管理を扱う、学習用のエディターサンプルです。 |

`docs/` は HTML、CSS、バニラJavaScript で動作します。フォント解析・アウトライン化には [opentype.js](https://github.com/opentypejs/opentype.js)、アップロードフォントのプレビューには `FontFace API` を使用しています。

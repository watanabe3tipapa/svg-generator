## docs/index.html について

`docs/index.html` は、ブラウザ上で動作するロゴSVGジェネレーターのWebアプリケーションです。フォントのアップロードとアウトライン化（文字をパスに変換）をクライアントサイドで実行できます。

### 主な機能

1. **テキストのカスタマイズ**
   - 任意のテキストを入力してロゴを生成
   - フォントサイズ、色、背景色の調整
   - ストローク幅の設定

2. **フォント管理**
   - Webフォント（Inter、Noto Sans JP）の使用
   - カスタムフォント（.ttf/.otf/.woff/.woff2）のアップロード
   - アップロードしたフォントはローカルで処理され、サーバーに送信されません

3. **アウトライン化**
   - opentype.jsを使用して文字をパスに変換
   - フォント依存を排除し、どの環境でも同じ表示を保証
   - SVGにフォントをbase64形式で埋め込むオプション

4. **アイコンとレイアウト**
   - アイコン（円形、四角形）の追加
   - レイアウト（中央、左寄せ、右寄せ）の選択
   - カスタム幅・高さの設定

5. **プレビューとダウンロード**
   - リアルタイムプレビュー
   - SVGファイルのダウンロード

### 技術スタック

- **HTML/CSS/JavaScript**: バニラJSで実装
- **opentype.js**: フォント解析とアウトライン化
- **FontFace API**: アップロードしたフォントの動的読み込み
- **Google Fonts**: Inter、Noto Sans JPの使用

### ファイル構成

```
docs/
├── index.html    # メインHTMLファイル
├── app.js        # アプリケーションロジック（353行）
└── style.css     # スタイルシート（155行）
```

### 主要な実装

- **フォントアップロード処理**: opentype.jsでフォントを解析し、FontFace APIで動的に読み込み
- **SVG生成**: テキスト要素またはパス要素としてSVGを生成
- **アウトライン化**: グリフをパスデータに変換し、フォント非依存のSVGを作成
- **フォント埋め込み**: base64エンコードでフォントをSVG内に埋め込み

### デプロイ

GitHub Pagesで公開されており、静的ホスティングで動作します。すべての処理はクライアントサイドで完結するため、サーバーサイドの処理は不要です。

## app/ について

`app/` は、シンプルなSVGジェネレーターの基本実装です。ランダムな長方形を追加してSVGを生成・ダウンロードできます。

### 主な機能

- **SVGキャンバス設定**: 幅、高さ、背景色の指定
- **長方形の追加**: ランダムな位置・サイズ・色の長方形を生成
- **プレビュー表示**: リアルタイムでSVGをプレビュー
- **SVGダウンロード**: 生成したSVGをファイルとして保存

### ファイル構成

```
app/
├── index.html    # メインHTML（37行）
├── app.js        # アプリケーションロジック（92行）
└── styles.css    # スタイルシート（496バイト）
```

### 技術的特徴

- **SVG DOM操作**: `document.createElementNS`を使用したSVG要素の動的生成
- **XMLSerializer**: SVGをXML文字列に変換してダウンロード
- **シンプルな設計**: 学習用・プロトタイプ用途に最適

## app2/ について

`app2/` は、インタラクティブなSVGエディターの高度な実装です。図形の追加、移動、リサイズ、レイヤー管理などの機能を備えています。

### 主な機能

1. **図形の追加**
   - 長方形と円の追加
   - カスタマイズ可能な色とストローク

2. **インタラクティブ編集**
   - ドラッグ&ドロップで図形を移動
   - ハンドルを使った図形のリサイズ
   - 4つのコーナーハンドル（NW, NE, SW, SE）

3. **レイヤー管理**
   - レイヤーパネルで図形の一覧表示
   - レイヤーの表示/非表示切り替え
   - レイヤーの前後移動（重なり順の変更）

4. **選択とプレビュー**
   - 図形のクリック選択
   - 選択図形のハイライト表示
   - リアルタイムプレビュー

5. **SVGダウンロード**
   - 編集結果をSVGファイルとして保存

### ファイル構成

```
app2/
├── index.html    # メインHTML（43行）
├── app.js        # アプリケーションロジック（405行）
└── styles.css    # スタイルシート（1175バイト）
```

### 技術的特徴

- **SVGPoint変換**: `svgPoint()`関数でクライアント座標をSVG座標に変換
- **ドラッグ&ドロップ**: マウスイベントを使った直感的な操作
- **リサイズハンドル**: 4つのコーナーハンドルで図形のサイズ変更
- **レイヤーシステム**: 配列の順序で重なり順を管理
- **状態管理**: `elements`配列で全図形の状態を管理
- **リアルタイム更新**: DOM操作とフルレンダリングのハイブリッド方式

### 使用例

1. 「長方形追加」または「円追加」ボタンで図形を追加
2. 図形をクリックして選択
3. ドラッグして移動、またはハンドルをドラッグしてリサイズ
4. レイヤーパネルで重なり順を調整
5. 「SVG ダウンロード」で保存
